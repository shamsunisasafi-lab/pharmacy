طریقه اجرا (فقط یک بار):
1) پوشه pharmacy-app-v3 را در VS Code باز کنید (File > Open Folder).
2) Terminal > New Terminal را بزنید.
3) این دو دستور را بنویسید:
   npm install
   npm run dev
صفحه به‌صورت خودکار در مرورگر باز می‌شود.

نیاز: Node.js نسخه 18 یا بالاتر (از nodejs.org نصب کنید).

عکس واقعی دوا‌ها: داخل پوشه public/images بگذارید. نام فایل‌ها در public/images/README.txt نوشته شده است.
